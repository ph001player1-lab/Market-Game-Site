# Захвати рынок — сайт игры

Статический лендинг бизнес-симулятора «Захвати рынок».
Обычный HTML: никаких сборок, зависимостей и внешних сервисов.
Домен: **marketgame.club**

## Состав репозитория

```
index.html               страница целиком: весь текст и вся вёрстка внутри
CNAME                    домен для GitHub Pages (одна строка: marketgame.club)
favicon.svg              иконка вкладки браузера
og.jpg                   превью для Telegram, WhatsApp и соцсетей
assets/hero.jpg          иллюстрация на первом экране
assets/tools.jpg         панель инструментов игрока
assets/author.jpg        фотография автора
assets/Manrope.woff2     шрифт основного текста
assets/Unbounded.woff2   шрифт заголовков
```

Шрифты лежат внутри репозитория, а не подгружаются с Google Fonts.
Сайт полностью работает без обращений к внешним сервисам — для аудитории
из России это существенно.

---

## Шаг 1. Публикация на GitHub Pages

1. Создайте новый репозиторий на github.com. Публичный, без README —
   он уже есть в этих файлах.
2. Загрузите туда все файлы, **сохранив структуру**: папка `assets`
   должна остаться папкой. Через веб-интерфейс: `Add file` → `Upload files`,
   перетащите содержимое папки целиком.
3. Откройте `Settings` → `Pages`.
4. В блоке `Build and deployment`:
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)`
5. Нажмите `Save`.

Через одну-две минуты сайт появится по временному адресу вида
`https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

Файл `CNAME` уже лежит в репозитории, поэтому GitHub сразу попробует
переключиться на `marketgame.club`. Пока не настроен DNS, сайт по домену
открываться не будет — это нормально, переходите к шагу 2.

---

## Шаг 2. Подключение домена marketgame.club в Dynadot

### 2.1. Открыть настройки DNS

1. Войдите в аккаунт на dynadot.com.
2. Слева выберите `My Domains` → `Manage Domains`.
3. Отметьте галочкой `marketgame.club` и нажмите `DNS Settings` в панели
   действий сверху. Либо кликните по имени домена и откройте вкладку
   `DNS Settings`.

### 2.2. Выбрать режим

В выпадающем списке вверху выберите **`Dynadot DNS`**.

Другие варианты не подойдут:
- `Dynadot Parking` — заглушка регистратора
- `Forwarding` — редирект, домен в адресной строке заменится на github.io
- `Custom DNS` — только если вы переносите домен на сторонние серверы
  имён вроде Cloudflare

Если Dynadot уже создал записи для парковки, **удалите их** перед
добавлением своих.

### 2.3. Записи для самого домена (Domain Record)

Четыре записи типа `A` — это адреса серверов GitHub Pages:

| Тип | Значение |
|---|---|
| A | `185.199.108.153` |
| A | `185.199.109.153` |
| A | `185.199.110.153` |
| A | `185.199.111.153` |

Дополнительно можно добавить четыре записи `AAAA` для IPv6. Не обязательно,
но лишним не будет:

| Тип | Значение |
|---|---|
| AAAA | `2606:50c0:8000::153` |
| AAAA | `2606:50c0:8001::153` |
| AAAA | `2606:50c0:8002::153` |
| AAAA | `2606:50c0:8003::153` |

### 2.4. Запись для www (Subdomain Record)

В разделе `Subdomain Records`:

| Субдомен | Тип | Значение |
|---|---|---|
| `www` | CNAME | `ВАШ-ЛОГИН.github.io` |

Именно `ВАШ-ЛОГИН.github.io` — без названия репозитория, без `https://`
и без слэша в конце. Например: `ph001player1-lab.github.io`

### 2.5. Сохранить

Нажмите `Save DNS` внизу страницы. Без этого записи не применятся.

## Шаг 3. Дождаться и включить HTTPS

Обновление DNS занимает от пятнадцати минут до нескольких часов,
изредка до суток.

Проверить, что записи разошлись, можно на dnschecker.org: введите
`marketgame.club`, тип записи `A`. Должны появиться те же четыре адреса
`185.199.10x.153`.

Когда домен заработает:

1. Вернитесь в `Settings` → `Pages` вашего репозитория.
2. В поле `Custom domain` должно стоять `marketgame.club`.
   Если пусто — впишите вручную и нажмите `Save`.
3. Дождитесь зелёной отметки `DNS check successful`.
4. Поставьте галочку **`Enforce HTTPS`**.

Сертификат GitHub выпускает сам и бесплатно, но не мгновенно: галочка
`Enforce HTTPS` может оставаться недоступной ещё час-полтора после того,
как DNS заработал. Если она серая — зайдите позже.

После этого сайт открывается по `https://marketgame.club`,
а `www.marketgame.club` автоматически на него перенаправляется.

## Превью ссылки в Telegram

В `index.html` уже прописан домен `marketgame.club`, поэтому при отправке
ссылки в чат подтянется картинка `og.jpg` с заголовком.

Telegram кэширует превью надолго. Если вы отправляли ссылку до того, как
сайт заработал, и превью не появилось — отправьте адрес боту `@WebpageBot`
и нажмите `Update preview`.

Если домен когда-нибудь сменится, поправьте три строки в `index.html`:

```html
<link rel="canonical" href="https://marketgame.club/">
<meta property="og:image" content="https://marketgame.club/og.jpg">
<meta property="og:url"   content="https://marketgame.club/">
```

и содержимое файла `CNAME`.

## Что где менять

| Что | Где искать в `index.html` |
|---|---|
| Ссылка на группу | `t.me/Market_Game_by_Nickbv` |
| Ссылка на личный Telegram | `t.me/nickbv` |
| Число участников, длительность хода, формат | блок `<dl class="specs">` |
| Биография автора | блок `<ul class="regs">` |
| Инструменты игрока | блок `<div class="tools">` |
| Цвета | переменные в начале `<style>`: `--red`, `--ink`, `--paper` |

Текст правится прямо в HTML между тегами — это обычные абзацы,
никакого шаблонизатора нет.

Чтобы заменить картинку, положите новый файл в `assets` под тем же именем.
Размеры: `hero.jpg` — 820 пикселей по ширине, `tools.jpg` — 600,
`author.jpg` — 560×700, `og.jpg` — строго 1200×630.

## Правка через веб-интерфейс GitHub

Ставить что-либо на компьютер не нужно:

1. Откройте `index.html` в репозитории.
2. Нажмите на карандаш в правом верхнем углу.
3. Внесите правки.
4. Внизу нажмите `Commit changes`.

Сайт обновится сам через минуту-две. Если изменения не видны — обновите
страницу с очисткой кэша: `Ctrl + F5` в Windows, `Cmd + Shift + R` в macOS.
